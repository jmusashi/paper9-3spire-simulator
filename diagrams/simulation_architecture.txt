OVERVIEW
--------
The 3Spire Invariant simulation models N agents, each maintaining three
continuity spires bound by an invariant envelope. An orchestrator monitors
spire alignment and enforces the envelope without replacing the invariant.

======================================================================
SPIRE INTERACTION MODEL
======================================================================

  Each agent maintains three spires that interact through the envelope:

  S1(t+1) = (S1(t) + invariant) / 2          [HiveSync pull]
  S2(t+1) = (S2(t) + invariant) / 2          [HiveSync pull]
  S3(t+1) = (S3(t) + invariant) / 2          [HiveSync pull]

  If S1(t) = 0 and S2(t) > 0 and S3(t) > 0:
    S1(t) = (S2(t) + S3(t)) / 2              [Stabilization]

  E(t) = 1 if any Si(t) > 0, else 0          [Envelope status]
